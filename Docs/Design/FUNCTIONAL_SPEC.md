# 기능명세서

`Docs/Design/USECASE.md`의 유스케이스(UC01~UC31)를 기능 단위로 상세화한 문서다. 기능ID(FS-xx)는 UC 번호와 1:1로 대응한다. 예외/제약사항 열은 현재 구현(`Backend/`) 기준으로 맞췄다. 명세 외로 구현된 기능(로드맵 코치, 알림함 등)은 `Docs/Design/USECASE.md` 2절 UX1~5를 참고한다.

`화면 연결` 열은 **살아 있는 화면이 그 기능의 API를 실제로 부르는지**를 표시한다. 기준은 `Frontend/src/App.jsx`에서 도달하는 렌더 트리(`Home` / `SubPage` → `RoadmapGuide`·`TaxAssistantPage`·`ExpenseTracker`·`BusinessPlanPage`·`AnnouncementAnalyzer` / `MyPage`)다. 이 열은 Backend 구현 여부가 아니라 화면 연결 여부만 말하며, 이 문서가 화면 연결 현황의 정본이다.

- `○` — 살아 있는 화면이 부른다
- `△` — 기능의 일부 경로만 연결됐거나, 부르는 코드가 **죽은 코드**다. 죽은 코드는 `Frontend/src/pages/TaxTool.jsx`와 `Frontend/src/pages/GovExplorer.jsx` 둘이며 어디서도 import·렌더되지 않는다
- `✕` — 부르는 화면이 없다. Backend·LLM 경로는 살아 있어 화면만 붙이면 동작한다

## 4. 지출 분석

지출관리 화면(`Frontend/src/pages/ExpenseTracker.jsx`, 전체 메뉴 → "지출관리")이 부른다. 마이페이지 안에 있던 직접 입력식 목업 화면은 제거하고 별도 메뉴로 분리했다. 기능 정리는 `Docs/reports/FEATURE_ROADMAP_EXPENSE.md` 2절 참고.
