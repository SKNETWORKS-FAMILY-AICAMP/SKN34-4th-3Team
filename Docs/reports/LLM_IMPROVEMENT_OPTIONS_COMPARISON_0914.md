# 통합 이슈의 LLM 개선안, 기존 실험과 비교

2026-09-14 기준 문서 비교. [통합 이슈 보고서의 결함 44·45](INTEGRATION_ISSUES_0914.md)를 제안 목록으로 보고, 번호가 붙은 [최초 평가](01_EVAL_BASELINE.md)·[정확도 개선](02_ACCURACY_IMPROVEMENT.md)·[세금 최종 실평가](03_TAX_FINAL_RESULT.md)·[종합 보고서](04_FINAL_REPORT.md)의 측정 결과와 대조했다. **새 제안은 아직 성능을 측정하지 않았으므로 아래 효과는 예상이며, 기존 수치를 새 제안의 성과로 읽어서는 안 된다.** 통합 이슈 문서의 조치 방향을 이 보고서의 작업 지시로 취급하지 않았다.

## 판단

기존 실험의 대표 장기 요청은 총 32.32초 중 **근거 충분성 판정 LLM 2회가 20.73초**, 검색·Rerank가 4.36초였다. 그래서 검색 단계만 더 병렬화하거나 검색어 수를 줄이는 방식으로 큰 단축을 장담하기 어렵다. 반대로 판정 자체를 줄이는 실험은 실제로 빨라졌지만 세금 통과율이 떨어졌다. **정확도를 우선한다는 기존 결정과 가장 잘 맞는 새 제안은 결과가 버려지는 라우터 호출 제거와, 계산 경로의 프로필 활용이다.** 전자는 속도, 후자는 불필요한 정보 요청 감소에 초점이 다르다.

효과 확인 시에는 같은 질문·인덱스·Cohere 정상 연결을 유지하고, 변경 전후의 라우터 단계 시간과 전체 응답 시간, 세금 턴 통과율을 함께 비교해야 한다. 사용자 정보 선채움은 답변에 사용한 값과 가정이 실제 프로필과 일치하는지도 확인해야 한다. 이 문서는 비교·우선순위 판단만 기록하며 코드 변경이나 새 평가는 수행하지 않았다.
