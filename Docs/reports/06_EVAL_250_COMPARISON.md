# LLM LangGraph holdout250 개선 전후 비교 — 2026-09-16

## 결론

### 통과 기준

- **답변 통과**: 답변별로 지정된 영역 분류, 응답 상태, 차단 여부, 근거 포함, 필수 문구, 답변 길이 조건을 모두 만족한 경우다. 하나라도 만족하지 못하면 미통과다.
- **전체 대화 통과**: 하나의 2개 답변 대화가 모두 통과한 경우다.
- **Guardrail 통과**: 차단해야 할 질문은 차단하고 정상 질문은 차단하지 않은 경우다.
- **정답 정책 완전 검색**: 질문에 지정된 정답 정책을 상위 5개 검색 결과에서 빠짐없이 찾은 경우다.

통과는 평가기에 미리 정의된 자동 검사에 대한 정답 판정이다. 답변의 모든 문장에 대한 사실 검증이나 세금 계산 금액의 정확성까지 보증하는 지표는 아니다.

## 지표 해석 범위

- 정책 R@5는 문항별 정답 정책 중 상위 5개에 포함된 비율의 평균이다.
- 세금·로드맵 통과율은 route, status, 차단, grounded, 필수 문구 등 evaluator가 관찰할 수 있는 자동 검사 결과다.
- 세금 계산 대화의 계산값 자체는 구조화된 결과로 노출되지 않으므로 이번 자동 지표는 금액 정확도를 보증하지 않는다.
- `guardrail_reason` 발생 수는 실패 수와 동일하지 않다. 기대된 범위 밖 차단도 해당 집계에 포함된다.
